گفت‌وگو

این نسخه بدون اتصال API کار می‌کند و پاسخ‌های سادهٔ محلی می‌دهد. برای هوش مصنوعی واقعی باید یک سرور امن به API وصل شود؛ کلید API را در این فایل عمومی قرار نده.

یادآورها

یادآورها در همین مرورگر ذخیره می‌شوند. اعلان‌ها ممکن است به اجازهٔ مرورگر نیاز داشته باشند و این صفحه برای هشدار دقیق باید باز بماند.
